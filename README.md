# 钢铁防线 · 坦克大战

一个无需安装依赖、无需后端的 HTML Canvas 坦克小游戏。支持电脑键盘和手机触屏。

## 运行

直接用现代浏览器打开 `index.html`，或在仓库目录运行：

```sh
python3 -m http.server 8000
```

然后在浏览器访问 `http://localhost:8000`。

## 操作

- WASD 或方向键：移动和转向
- 空格：开火（可按住连续射击）
- P：暂停或继续
- 重新开始：重置战场与分数
- 手机：使用战场下方的方向按钮和开火按钮

消灭一辆敌方坦克得 100 分，清空敌人后进入下一波。敌人的数量和速度随波次提升。砖墙可以被子弹摧毁；金色维修包恢复一点装甲。装甲归零后游戏结束，切出窗口会自动暂停。

## 文件

- `index.html`：页面和操作界面
- `style.css`：自适应布局与视觉样式
- `game.js`：游戏循环、碰撞、敌人行为和绘制

无外部资源、第三方脚本或 API 密钥要求。可部署到 GitHub Pages 等静态网站托管服务。
